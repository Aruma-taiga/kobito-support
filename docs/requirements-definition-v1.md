## 1. 申込から契約成立までの流れ（決定：taiga 2026-10-23）

1. LINE等で相談 → 初回ヒアリング（無料、約30分）
2. 当社が申込フォームのリンクを送る
3. お客様がフォームに入力して送信（＝申込み）
4. 当社が内容を**審査**し、審査を通れば**初月分の請求書を送る**（支払方法に応じた案内つき。カードはKOMOJUの支払い画面へのリンクで、ここでカードを登録すると翌月から自動課金。コンビニは支払い番号、銀行振込はCingulataの口座）。お断りする場合は請求書を送らずに連絡する
5. **初月分の入金を確認した時点で契約成立**。成立の通知を送り、クレジットが使えるようになる（**月額は前払い**）
6. 初月分の請求書の支払期限を過ぎても入金がなければ、申込みは失効する（規約第4条4項。**発行から7日**、taiga決定）。システムは期限切れの申込みを「失効」にし、お客様に知らせる

**経緯：** 10/22は「承諾の通知で成立」、10/23に一度「フォームからそのまま決済し、決済の完了で成立」としたが、taigaの指示（2026-10-23 17:44）で上の「請求書の送付 → 入金確認で成立」に変更。審査は請求書を送る前に行うので、成立後の返金は原則発生しない。規約第4条の修正と弁護士の確認が必要（規約スレッドへ依頼済み）。
